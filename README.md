# SQL Projects Portfolio

Практические проекты по работе с реляционными базами данных и языком SQL.

## 🛠 Стек технологий
* PostgreSQL, SQL (DDL, DML, CTE, Window Functions)
* Анализ планов запросов (EXPLAIN ANALYZE), индексы, транзакции

## 📂 Содержание
* **SQL_01 - SQL_05:** Базовые запросы, фильтрация, соединения (JOIN), агрегации и подзапросы.
* **SQL_06 - SQL_08:** Работа с индексами, оптимизация и интеграция функций.
* **SQL_09:** OLAP и аналитические функции.
* **SQL_10:** Уровни изоляции транзакций.
* **SQL_11:** Функции, процедуры и триггеры (PL/pgSQL).
* **SQL_12:** Проектирование хранилища данных (Data Warehouse).
